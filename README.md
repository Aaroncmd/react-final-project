# ScreenScout

ScreenScout is a React movie discovery app that lets users search movies and series, sort results, and open detailed title pages using the OMDb API.

## Features

- Search for movies and series
- Browse title cards in a responsive grid
- Sort results by year or alphabetically
- View detailed information for each title
- Clean multi-page React Router flow

## Tech Stack

- React
- React Router
- Axios
- Font Awesome
- OMDb API

## Available Scripts

### `npm start`
Runs the app in development mode.

### `npm test`
Launches the test runner.

### `npm run build`
Builds the app for production.
